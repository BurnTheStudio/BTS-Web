## The symptom

Healthy sign-ups and a busy dashboard, but weekly active numbers plummeted after day three. Queries on the primary telemetry feed took upwards of four seconds, and users dropped off before reaching initial value.

## What was really going on

Scope had accumulated across four disparate product iterations without documentation. The critical onboarding path required seven unnecessary configuration steps before the user encountered the primary analytics screen. Concurrently, unindexed join queries on the activity table locked connections during peak sign-up windows.

## How we solved it

We conducted a forensic code audit on day one, mapped the real user journey, and cut five configuration screens from the initial loop. In engineering, we introduced targeted indexes, refactored high-cardinality queries, and wrapped the critical path in regression tests before shipping changes in weekly slices.

## What the client got

A direct two-step path to the core product experience, median query latency dropped from 4,100ms to 120ms, and a retention curve that stabilized across the first 30 days of real traffic.
